## 给公众号本地执行 Agent
1. 读取 xingtu-vault PR #12 v4 目录及 manifest；下载整包，按 SHA-256 校验。不可从公开设计仓寻找私有正文、图片或凭据。
2. 人工批准版式后，使用本地安全环境的公众号 API：上传封面 thumb 与三张正文图，替换 HTML 占位符。
3. 只调用 draft/add 创建**私人草稿**，随后 draft/get 校验封面、标题、摘要、正文和图片；失败不得标记成功，不得覆盖既有草稿。
4. 留下本地加密/私有回执与脱敏日志，禁止把 access_token、AppSecret、media_id、个人资料推送公共设计仓。
5. 本任务不授权公开发布/群发/定时，不修改系统配置。

## 独立验收
设计仓 PR 可合并与否由 Chat 裁决；内容发布由人工最终审核。不要把已上传 GitHub 误认成已创建微信草稿。
