# 官方截图引用规范 v1（待审）

本页补充现有 Evidence First 提案，适用于用官方文档或公开产品页面支撑具体论点的图文。真实浏览器采集是素材真实性的要求；页面上出现功能描述，不证明采集者实际运行或验证过该功能。本页不改变仓库主规范，也不包含任何私有文章、账号或执行日志。

## 采集与保存

1. 用真实浏览器访问官方原地址，确认域名、实际页面标题和目标段落。记录请求 URL 与实际落地 URL；重定向到登录、验证码、错误页时明确失败，不用概念图顶替成功截图。
2. 原始截图单独保存并保持不可变。采集后立即记录 SHA-256、时间及时区、页面标题、浏览器视口和可见内容。哈希用于验证文件一致性，不单独证明来源或真实性。
3. 裁切、缩放、压缩或隐私遮盖形成独立派生文件，保留原图。记录父图哈希、裁切范围和转换方式；不覆盖原图，不用生成式补全、拼接或改字改变功能与权限含义。
4. 优先截取直接支撑论点的局部，同时保留足够标题、前提和限制。不得裁掉“原型”“仅限某计划”“需管理员授权”等条件，造成产品能力误读。
5. 登录态页面先核查账号名、头像、邮箱、组织、通知、地址栏参数、API 密钥、会话内容。含敏感信息的原图只存获准的私有位置；公网只放已批准的派生图与去敏记录。

建议目录：`original/` 保存原图，`edited/` 保存派生图，`evidence.json` 保存非敏感记录。目录名只表达用途，不暗示已通过验收。

## 使用权与引用边界

- 页面可访问、项目开源、官方提供截图，均不能直接推出截图拥有开放转载许可。代码许可证也未必覆盖网页、商标、人物或第三方素材。
- 记录明确许可的原文链接及适用范围；无明确许可时写“未确认开放许可”，不要改写为“已授权”。如拟以必要引用使用，记录引用目的、最小必要范围、署名及原始链接，交最终发布者审阅；本规范不替代对具体用途的法律判断。
- 保留版权和平台来源标记，不制造官方背书。若无法确定使用范围，保留内审素材，以文字转述和官方链接替代公开图片。
- 禁止把私有文章正文、账号凭据、私有草稿标识或内部采集日志复制进公共设计仓。

## 排版与图注

官方图保留原貌，外围版式使用纯白 `#FFFFFF`、黑 `#1A1A1A` 和橙红 `#F2644F`；品牌配色不用于重涂原始界面。每图只服务一个具体论点，按信息增量选图，不以数量补齐为目标。

图注至少说明：官方来源与原始链接、采集日期、真实文档截图或界面截图、裁切/遮盖情况，以及证据边界。例如：“来源：某产品官方文档，采集于 YYYY-MM-DD；局部裁切，展示授权前提，非本次运行实测。”

正文尺寸随容器缩放；在 375px 和 414px 预览检查文字是否可读、限制条件是否仍可辨认、图片与上下文是否对应、图注是否换行溢出。过长截图应按论点分段裁切，避免把整页缩到不可读。

## 最小证据记录

| 字段 | 要求 |
|---|---|
| asset_id / representation | 稳定标识；document_screenshot 或 product_screenshot |
| source_url / final_url / page_title | 原始地址、最终地址、真实页面标题 |
| captured_at / viewport | 含时区时间；浏览器视口尺寸 |
| original_path / original_sha256 | 原图路径与哈希 |
| edited_path / edited_sha256 / parent_sha256 | 派生图与父图关系 |
| transformation | 裁切坐标、缩放、压缩、遮盖；未修改则明示 |
| claim / placement / caption | 支撑论点、放置位置、实际图注 |
| permission_status / permission_source | 已获许可或未确认；依据链接 |
| privacy_review / reviewer / review_status | 核查范围、审阅人、待审或通过 |
| failure / limitations | 不可访问原因、未验证事项，不以空值冒充通过 |

## 通用样例与验收

[截图引用卡样例](03_官方截图引用卡样例.html)仅展示空素材位和引用字段，不伪造任何官方页面。替换为获准使用的真实派生图后才可作为文章素材。

验收需逐项证明：来源可核；原图哈希一致；派生关系可追；论点与截图相符且限制条件保留；权限状态明确；隐私核查完成；375/414px 版式可读。证据缺失写待审；采集成功、素材入库、运行测试通过和公开发布分别记录。
